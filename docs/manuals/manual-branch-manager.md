# دليل مدير الفرع

> لقطة شاشة مقترحة: الصفحة الرئيسية لمدير الفرع.

## 1. مسؤولياتك الأساسية

- متابعة المبيعات اليومية
- متابعة المشتريات والاستلام
- مراجعة الرصيد والحركة
- الإشراف على فريق الكاشير والمخزن داخل الفرع

## 2. بداية اليوم

1. سجّل الدخول.
2. اختر الفرع الصحيح من أعلى الشاشة إذا كان لديك صلاحية متعددة الفروع.
3. راجع لوحة الفرع والرصيد الحالي.

> لقطة شاشة مقترحة: مبدل الفروع في أعلى الواجهة.

## 3. المشتريات

عند تسجيل فاتورة شراء:

1. افتح صفحة المشتريات.
2. اختر المورد والخزينة والمخزن.
3. أضف الأصناف والكميات وسعر الشراء.
4. راجع الإجماليات والضريبة إن كانت مفعلة.
5. احفظ الفاتورة.

### تنبيه

- إذا كانت ضريبة المشتريات مفعلة فالإجمالي النهائي سيزداد تلقائيًا.
- لا تغيّر الخزينة أو المورد بعد مراجعة المبالغ إلا إذا أعدت التحقق من الإجمالي.

> لقطة شاشة مقترحة: شاشة المشتريات قبل الحفظ.

## 4. التحويلات والمخزون

- استخدم التحويلات عند نقل صنف بين الفروع أو المخازن.
- راجع تقارير المخزون قبل طلب شراء جديد.
- افتح تنبيهات إعادة الطلب بشكل دوري.

## 5. الموارد البشرية

- راجع الرواتب والسلف والخصومات إذا كانت ضمن صلاحياتك.
- لا تؤكد دفع الراتب إلا بعد مراجعة المبلغ المتبقي لهذا الشهر.

> لقطة شاشة مقترحة: شاشة HR داخل الفرع.

## 6. التقارير

راجع بشكل يومي:

- مبيعات الفرع
- أعلى الأصناف حركة
- النقدية مقابل المدفوعات الإلكترونية
- أي فروق غير معتادة بين الفترات

## 7. نهاية اليوم

1. تأكد من إغلاق الوردية عند الحاجة.
2. راجع ملخص المبيعات.
3. راجع أي مشتريات أو تحويلات لم تُعتمد.
4. صعّد المشكلات الحرجة قبل مغادرة اليوم.
