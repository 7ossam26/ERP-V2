# دليل أمين المخزن

> لقطة شاشة مقترحة: صفحة المخزون أو الجرد.

## 1. مهامك اليومية

- استلام الأصناف الواردة
- متابعة الرصيد
- تنفيذ التحويلات
- المشاركة في الجرد
- مراجعة الفروق

## 2. عند استلام مشتريات

1. افتح فاتورة الشراء المعتمدة.
2. تأكد من الصنف والكمية.
3. طابق الواقع مع النظام.
4. بلّغ فورًا بأي اختلاف قبل صرف أو تحويل الصنف.

## 3. التحويل بين المخازن أو الفروع

- افتح صفحة التحويل.
- اختر المصدر والوجهة.
- أضف الأصناف والكميات.
- احفظ العملية بعد مراجعة كل سطر.

> لقطة شاشة مقترحة: نموذج تحويل مخزني.

## 4. الجرد

أثناء الجرد:

1. ابدأ جلسة الجرد الصحيحة.
2. تأكد من المخزن أو الفرع.
3. أدخل الكميات بدقة.
4. راجع الفروق قبل الإقفال.

### تنبيه

- لا تُعدل الجلسة بعد الإغلاق إلا حسب الصلاحيات المعتمدة.
- أي فرق كبير يجب تصعيده فورًا.

## 5. التعديلات المخزنية

- استخدم تعديل المخزون فقط للحالات المعتمدة.
- أضف سبب واضح للتعديل.
- لا تُجرِ تعديلًا بلا مستند أو موافقة.

## 6. تقارير مهمة

- الرصيد الحالي
- الراكد
- تنبيهات إعادة الطلب
- جلسات الجرد المفتوحة

## 7. نهاية اليوم

1. تأكد من عدم وجود تحويلات معلقة.
2. راجع الأصناف الحرجة والمنخفضة.
3. أبلغ مدير الفرع بأي نقص أو فرق.
