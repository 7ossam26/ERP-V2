# خطة الدعم

## قنوات الاستقبال

- قناة أساسية: مجموعة دعم واتساب أو تذكرة داخلية متفق عليها
- قناة تصعيد: اتصال مباشر للمشكلات الحرجة
- مالك القرار: Owner أو من يفوضه

## تصنيف الشدة

- `P1 - حرج`
  - النظام متوقف كليًا
  - البيع أو تسجيل الدخول متعطل في الإنتاج
  - استجابة أولية: خلال 30 دقيقة
  - زمن بدء المعالجة: فوري

- `P2 - عالي`
  - تعطل جزء رئيسي مثل المشتريات أو المخزون أو التقارير الرئيسية
  - يوجد workaround محدود
  - استجابة أولية: خلال 4 ساعات عمل
  - بدء المعالجة: نفس يوم العمل

- `P3 - متوسط`
  - خلل بصري أو ترجمة أو تقرير غير عاجل
  - workaround متاح
  - استجابة أولية: خلال يوم عمل واحد
  - الجدولة: ضمن أقرب release patch

- `P4 - منخفض`
  - تحسينات وتجميليات وطلبات تغيير
  - استجابة أولية: خلال 3 أيام عمل
  - الجدولة: backlog

## آلية البلاغ

كل بلاغ يجب أن يحتوي على:

- اسم المستخدم والدور
- الفرع
- الصفحة أو الشاشة
- الخطوات لإعادة المشكلة
- النتيجة الفعلية
- النتيجة المتوقعة
- لقطة شاشة أو فيديو إن أمكن
- وقت حدوث المشكلة

## سياسة الإصدار

- إصلاحات `P1` و`P2` قد تُنشر hotfix بعد تحقق سريع.
- إصلاحات `P3` و`P4` تُجمع في patch release مجدول.
- أي تغيير على قاعدة البيانات يسبقه backup مؤكد.

## حدود الدعم

- دعم البيانات التشغيلية اليومية يقتصر على تصحيح الأعطال، لا إدخال البيانات نيابة عن المستخدم.
- طلبات التخصيص الجديدة تُقيَّم منفصلة عن دعم الضمان.
